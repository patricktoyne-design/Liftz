LIFT. WORKOUT APP (customised for Patrick)

Install: upload all files in this folder to the root of your existing GitHub repository, replacing the old files.
Open your GitHub Pages URL in Safari and refresh. If an old version remains, close the app and reopen the site in Safari.

What changed
- Plan rebuilt around your split: Chest/Triceps, Back/Biceps, Legs/Abs, Shoulders/Traps, Arms/Weak Points (Mon-Fri), one leg day.
- Only uses your garage gym: rack, barbell + bench, adjustable dumbbells, cable pulley, power tower (pull-ups, dips, hanging leg raises), leg attachment.
- Settings now has a plan editor: rename any exercise, change sets, reps and working weight. Changing reps or weight resets that exercise's progression target.
- Starting weights are conservative placeholders. Set your real ones in Settings before session one.
- Service worker is now network-first, so future updates show up without clearing the app.

Progression (unchanged)
- Hit the target on every set: next target +1 rep. After reaching prescribed reps +2 on every set, weight goes up by the increment and reps reset.
- Bodyweight exercises keep adding reps.

Data: this is a fresh v3 store. Old v2 history is not carried over because the exercises changed.
