LIFT. WORKOUT APP

Install: upload all 5 files to the root of your GitHub Pages repo, replacing the old ones. Open the site in Safari and refresh (twice if you still see the old version).

Plan: Mon Push, Tue Pull, Wed Legs & Abs, Thu Upper, Fri Shoulders & Arms, with the weights you gave.

Settings > Your plan
- Edit any exercise name, sets, reps, weight and jump (kg added on progression).
- Add exercises to any day, remove them, or reorder with the arrows.
- Leave Weight empty (or 0) to make an exercise bodyweight: it progresses by reps only.
- "Each side" marks one-arm / single-leg exercises.
- Reset plan to default restores the original five days and weights. History is kept.

Progression: hit the target reps on every set and next session's target goes up 1 rep. After reaching starting reps +2 on every set, weight goes up by the jump and reps reset.

Data: stored in this browser only (new v4 store; older versions' data is not carried over). Use Settings > Export / Import backup to move it between devices.
